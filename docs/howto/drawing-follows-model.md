# Drawing follows the model

Goal: a drawing width is a live view of the model. Edit the box width; the associative dim updates.

## Steps

1. Place a box.
2. **Mode → Draw** — the sheet is the viewport (title block on the paper).
3. Edit the primitive `a` (width) from 50 → 55 in the timeline.

## What “good” looks like

- Bounding-box X grows to 55 mm.
- The drawing is not a picture; it is the model seen from the front.
