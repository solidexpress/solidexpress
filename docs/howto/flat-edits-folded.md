# Flat edits the folded flange

Goal: change the flange length; `flat_length` recomputes. Folded and flat are one viewport split.

## Steps

1. **Mode → Sheet**.
2. Add a 30 mm flange.
3. Set length to 40 mm. Flat grows.

## What “good” looks like

- `flat_length` after edit > `flat_length` before.

Film: `flat_edits_folded`.
