# Update Context, never silent

Goal: a pad that reads a neighbor snapshot does not move when the neighbor grows, until you click **Update Context** on the consumer timeline row.

## Steps

1. Place a box (the neighbor).
2. Select it → marking menu **In-context pad**.
3. Edit the neighbor height. The pad volume stays put.
4. Click **Update Context** on the pad's timeline row.
