# Drawing BOM

Goal: BOM counts instances. Two placements of one seed → Qty 2.

## Steps

1. Place a cylinder.
2. **Place instance of selection** twice.
3. **Mode → Draw**. Balloons match the instance list.

## What “good” looks like

- `instance_list().size()` ≥ 2.
- The table is the assembly, not a typed list.
