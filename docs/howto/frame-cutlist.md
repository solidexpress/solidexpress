# Frame cut-list

Goal: four members of a rectangle; each `cut_length` is the path length.

## Steps

1. **Mode → Form** (rail replaces Modify).
2. Add four frame members around an 80 mm square.
3. Cut-list total = 320 mm.

## What “good” looks like

- Each member `cut_length` = 80 mm.

Film: `frame_cutlist`. Kernel: `[wave2][frame]`.
