# Modeled thread from a standard

Goal: cut a modeled thread on a cylindrical shaft and edit size from the timeline.

## Steps

1. Place a **cylinder** (shaft-like: taller than it is wide).
2. **Insert → Thread…** (or Modify → Thread). Boxes are refused.
3. The timeline opens the Thread PropertyPanel — pick an **ISO/UNC standard** (e.g. M10) to set major radius and pitch, then OK.

Film: `thread_standard`.
