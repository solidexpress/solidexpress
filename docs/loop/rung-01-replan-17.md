## Decisions (final — BUILD agents do not choose)

1. **Scope.** Only the 14 triage items change behaviour. The only status strings that change are the ones named in D12 and D13; every other string stays byte for byte (the e2e suites assert them).
2. **Jaw preview (T2).** The preview is the committed shape at every stage: after click 1 a rotated rectangle (long axis centre → pointer, `half_w = 0.4 × length`, `JAW_PREVIEW_ASPECT := 0.4`); after click 2 the committed rectangle with `half_w = max(|(tip-ctr)·nrm|, 1.5 mm)` (`JAW_PREVIEW_MIN_HALF_W_MM := 1.5`). Commit and the `JAW_ZERO_WIDTH` refusal are untouched.
3. **Polygon (T9).** The pointer sits on the circumscribed circle: pointer AF = `√3 × |pointer − centre|`; flats stay horizontal; a typed size is the AF itself (nut `AF 20` unchanged). Same strings.
4. **DOF chip (T6).** After any undo / redo restore the chip reflects the live sketch: non-empty → `run_solve()`; empty → `—` (the text a fresh sketch shows).
5. **Glyphs (T7).** Anchors sit on the geometry (arc start/end for an arc end, tangent contact point for a tangent); a glyph may be pushed at most `GLYPH_MAX_OFFSET_PX := 40` from its anchor; at ≥ `GLYPH_LEADER_MIN_PX := 12` a 1 px leader joins it to the anchor; glyphs keep `GLYPH_LABEL_GAP_PX := 4` from every label (the glyph yields, labels never move for glyphs).
6. **Contour fill (T5).** `CONTOUR_FILL_ALPHA := 0.20`, `CONTOUR_FOCUS_ALPHA := 0.70`, plus a second inset outline (0.70 mm) on the hovered region. Skipped = outline only (unchanged).
7. **Hover hints (T1).** A hint that arrives during the 2.5 s status hold is **deferred** to the end of the hold (one timer), not dropped; a hover miss, a scroll-UI hover and a selected-body hover clear it (`hover_hint("")`); a newer status extends the hold. Wording unchanged.
8. **Timeline vs chips (T8).** The part chip row never moves (its x is fixed on purpose, N3). While it is visible and overlaps the Timeline's x-range the Timeline docks at `strip.end.y + 4`; otherwise at `top_inset`. New API `ViewportInteraction.selection_strip_global_rect()` and `signal selection_strip_laid_out`.
9. **Window (T12).** At startup, not headless and `SX_TEST_WINDOW` unset: maximise; if after 3 frames the window is smaller than the usable rect minus decorations by more than 8 px, size it to that rect. `project.godot` is not changed. The rule is a pure static function (`Main.window_fit_rect`) so headless tests can call it.
10. **Click ledger (T11).** `ViewportInteraction.last_click_disposition` + `signal click_disposition(text)`; `SX_INPUT_TRACE=1` prints `[input-trace] press (x,y) <disposition>`. No UI. WP3 fixes **only** the drop path the ledger shows; if 2 × 80 real-window trials are clean after the fixes it closes the item as environment (window-focus click) and says so with the tally. No retries, timers or double-click tricks.
11. **Marquee (T13).** Select tool, press on empty canvas, drag > `CLICK_SLOP`: left→right = **window** (all sample points inside, blue box `Color(0.35, 0.6, 0.95, 0.18)`), right→left = **crossing** (any sample inside or polyline crosses, green box `Color(0.35, 0.85, 0.45, 0.18)`); Shift / Ctrl on release adds; labels and glyphs are not targets; a press that moves < `CLICK_SLOP` is the old click; a press **on** an entity still drags it.
12. **Select wording (T10).** Part mode: `Selected body <id8>`, `Selected face <id8>`, `Selected edge <id8>`; box select `Selected body <id8>`; multi `<n> selected` unchanged. Sketch: `Selected 1 sketch entity`, `Selected <n> sketch entities`, `No sketch entities`. Every `begins_with("Selected ")` test still holds.
13. **Face vs body is by design** (D12 only names the level). No pick-order change.
14. **A8b is a checklist error.** Feature names are `<type> <index>`; the jaw sketch is `sketch 3`. No kernel change.
15. **A15 (T4).** Add tier `known-red` with a mandatory `reason=` key: not run by `--tier ci` or `--tier full`, listed (with its reason) by `--tier known-red`, new Makefile target `test-godot-known-red`. Product bugs and stale tests are **fixed**; a suite stays known-red only with a reason in one of three classes: `env:` (needs a GPU, display, network or a tool this box lacks), `stale-feature:` (tests behaviour the product removed on purpose; cite the PR) or `product:` with a tracking sentence. `make test-godot` must end `0 failed`. The test-godot recipe and `run_godot_suites.sh` stay unedited; `run_suites.sh` is WP5's.
16. **Walk twin.** `run_rung01_replan17_walk.gd` is a copy of the replan16 walk plus the sx-038 assertions (`WALK-SUMMARY stages=8 first_red=none`). The replan16 walk stays.
17. **Checklist.** sx-038 has 69 rows: the 64 of sx-037 (restated where #196–#207 changed behaviour) plus **N22** window (WP4), **N23** Timeline vs chips (WP4), **N24** sketch drag-box (WP3), **N25** DOF chip after undo (WP2), **N26** glyphs on their vertices (WP1); and soft-GL rule **51** (a dead first click is evidenced by the `[input-trace]` log line).
18. **PR rules for every BUILD PR.** Repo `github.com/solidexpress/solidexpress` only; ready (not draft); never self-merge; quick CI (linux kernel, godot-smoke, website-demos) green; do not wait for `windows-export` / `macos-kernel`; **do not edit `docs/plan/STATUS.md`** (notes go in the PR body); reproduce first.
