Support

Report bugs, ask questions, and track fixes on GitHub Issues.

Primary channel

All product support for SolidExpress goes through the public issue tracker. There is no separate support email or chat product.

Open GitHub Issues New issue

What to include

  • SolidExpress version (or git commit) and operating system
  • Steps to reproduce, or the failing build/export command
  • Relevant logs or screenshots
  • Whether you used a GitHub Release binary or built from source

Build help

For compiling from source, start with Build & run and the how-tos under docs/howto/ in the repository.
